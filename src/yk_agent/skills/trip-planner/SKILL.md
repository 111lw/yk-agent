## 方法论

生成攻略按以下顺序组织内容：

1. **开头一句话点题**：目的地 + 天数 + 针对该用户画像的一句话概括（如"节奏松弛、避开登山"）。
2. **逐日行程**：引用 route-agent 的产出，每天给出 上午/下午/晚间 安排；相邻活动需注明交通方式与
   大致耗时；每天结尾给一条"备选"（下雨/排队时换什么）。
3. **住宿建议**：按用户画像的 stay 偏好给 1~2 个区域建议（说明理由：离哪几天行程近）。
4. **美食安排**：行程中的餐饮点位优先来自 poi-agent 的餐饮候选；列出 2~3 个必吃清单。
5. **预算表**：引用 budget-agent 的分项数据，另起一行注明"大交通未含"；总额与用户预算对比，
   超支时给出削减建议（砍哪一档）。
6. **个性化理由**：单独一小节"为什么这样给你排"，引用真实画像记录（人格类型与 top 偏好），
   禁止编造画像里没有的依据。

## 输出要求

- 中文，用 markdown 小标题分节；预算用表格。
- 产出缺失的数据（如某类 POI 检索失败）如实标注"暂缺"，不编造。
- 总长度控制在 800 字内，信息密度优先。

## 边界

- 不做交易承诺（不出现"帮你订""保证有票"）。
- 不推荐画像 dislike 硬过滤掉的内容；也不主动提及被过滤的选择。
- 行程之外的问题（签证/包车/拼团）不在本技能范围，如实说明。
