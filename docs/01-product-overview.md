# 01 产品概览

## 定位

yk-agent 是一个**个性化旅游推荐智能体**：以用户画像（性格、心理、喜好）为核心驱动，通过对话为用户生成「真正适合 TA」的旅游攻略，并具备自我编排能力——智能体根据任务自行决定调用哪些子智能体、以何种顺序与并行度完成。

一句话：**不是"下一个行程规划工具"，而是"懂你的旅行顾问"。**

## 目标用户

| 用户群 | 典型诉求 | 画像侧重点 |
|---|---|---|
| 年轻自由行用户 | 个性化、小众、出片、性价比 | 节奏偏好、风格标签（探险/文艺/躺平） |
| 家庭出游 | 省心、安全、亲子友好 | 同行人构成、体力、饮食禁忌 |
| 银发/休闲客群 | 舒适、节奏慢、医疗服务可达 | 住宿标准、交通舒适度 |
| 商务+顺路游 | 时间碎片化、高效 | 时间约束权重极高 |

## 核心场景（MVP 覆盖前两个）

1. **对话式攻略生成**：「想去云南玩 5 天，预算 5000，不太想爬山」→ 完整攻略（行程/住宿/美食/预算表）。
2. **个性化追问与调整**：「第三天太赶了」→ 智能体理解并局部重排，且记住"你不喜欢太赶的节奏"。
3. **攻略对比**（V2）：同一目的地按不同人格出两版方案供选择，选择结果反哺画像。
4. **实时要素融合**（V2）：天气/机票价格/景点营业时间接入后动态修正方案。

## 产品原则

1. **画像驱动**：每次推荐都能说清"为什么推荐给你"（可解释性），这是信任基础。
2. **越用越懂你**：每轮对话抽取偏好回写画像；用户对攻略的修改/拒绝是最强的偏好信号。
3. **自主但有边界**：智能体自主编排完成任务，但只读操作自主并行、副作用动作必须经用户确认。
4. **冷启动不劝退**：首次使用用 3~5 轮引导对话建立基础画像，绝不一次甩 20 个问题。

## 非目标（明确不做）

- ❌ 交易闭环（下单/支付/出票）——只做推荐与规划，交易导流到第三方。MVP 期间一切"预订"类意图仅产出建议。
- ❌ 通用问答助手——超出旅游领域的对话礼貌拒答。
- ❌ 社交/UGC 社区——知识库内容由运营侧离线灌入。
- ❌ 多模态生成（生图/生视频）——V3 再评估。

## 成功指标（MVP 验收）

| 指标 | 目标 |
|---|---|
| 攻略可用率 | 生成的攻略无需大改即可使用的比例 ≥ 70%（人工评估 20 例） |
| 画像准确度 | 用户对"你的偏好画像摘要"的认可率 ≥ 80% |
| 任务成功率 | 端到端「对话→出攻略」完成率 ≥ 90% |
| 编排效率 | 平均单次攻略生成 ≤ 60s、子智能体调用无死循环（护栏生效） |
